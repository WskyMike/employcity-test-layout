# Тестовое задание - Адаптивная верстка

Проект создан в соответствии с методологией БЭМ и использует препроцессор SASS.

## Особенности реализации

### 1. Адаптивность
- Минимальное разрешение: 320px
- Максимальное разрешение: 1920px
- Используются CSS Grid и Flexbox

### 2. БЭМ методология
- Четкое разделение блоков, элементов и модификаторов
- Логичная структура файлов

### 3. SASS/SCSS
- Переменные для цветов, отступов, анимаций
- Миксины для повторяющегося кода
- Модульная структура

### 4. Кроссбраузерность
- Поддержка современных браузеров
- Autoprefixer для вендорных префиксов

### 5. Компоненты
- Универсальные кнопки с модификаторами
- Единые стили для ссылок
- Переиспользуемые компоненты

## Основные блоки (БЭМ)

- `.header` - Шапка сайта (липкая)
- `.hero` - Главная секция
- `.order` - Секция оформления заказа
- `.steps` - Шаги процесса
- `.form` - Форма заказа
- `.footer` - Футер
- `.button` - Универсальные кнопки
- `.nav` - Навигация
